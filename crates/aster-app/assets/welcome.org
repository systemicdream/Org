#+TITLE: Welcome to Aster
#+TODO: TODO NEXT | DONE

This is a plain Org file. Everything you see is ordinary text that any Org tool can read.

* Headings start with stars
Each extra star nests one level deeper.
** Like this
*** And this

* TODO Things to do have a keyword                                    :tasks:
Type TODO or DONE right after the stars.
** DONE Finished items turn green
** NEXT [#A] Priorities look like [#A]                                :urgent:

* Notes
- Lists start with a dash
- [ ] Checkboxes look like this
- [X] And this when done

* Shortcuts to try
(Cmd on macOS, Ctrl on Linux)
- Cmd/Ctrl+Enter :: tick a checkbox, or step a heading through TODO → DONE → none
- Alt+Enter :: new heading below this one
- Tab / Shift+Tab on a heading :: nest it deeper / bring it back out (children follow)
- Alt+Up / Alt+Down :: move a heading and everything under it
- Cmd/Ctrl+Z :: undo, Cmd/Ctrl+Shift+Z :: redo

Try typing `* ` at the start of a line to make a new heading.
Unicode works too: 日本語, Ελληνικά, emoji 🎉.
