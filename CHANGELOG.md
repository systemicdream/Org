## [0.1.0] - 2026-11-23

The first release.

### Writing
- An Org editor that formats as you type: headings, emphasis, lists, checkboxes, tables,
  links, source blocks with syntax highlighting, and images. Markup appears when the cursor
  is on it.
- Folding, outline moves (move, indent and outdent whole subtrees), TODO states, priorities,
  tags, a date picker for SCHEDULED and DEADLINE, and a properties panel.
- A slash menu for inserting blocks, and a command palette for everything else.
- Find and replace, undo and redo, autosave, and Japanese and other IME input.

### Organizing
- A notes folder with a file tree, quick open, full-text search, tags, and `id:` and file
  links between notes. Create, rename and delete (to the trash) notes and folders.
- An agenda (day and week), a to-do list, and Org match searches.
- Capture with configurable templates, refile anywhere in the folder, and archive.
- Changes made by other editors and sync services are picked up; sync conflicts are flagged.

### Appearance and setup
- A Fluent-inspired design with light and dark themes, the system accent color or your own,
  and translucent windows on macOS and KDE Plasma.
- A first-run guide that creates a notes folder with a welcome note and a starter inbox.
- Settings for theme, accent, transparency, text size, keyboard shortcuts and capture
  templates.
- Optional Emacs and Vim keys.

### Releases
- Packages for macOS (universal `.dmg`), Flatpak, Debian/Ubuntu (`.deb`), Fedora (`.rpm`)
  and a Linux tarball.
- A daily check for new versions (can be turned off), and local crash reports that you can
  choose to send as a GitHub issue.
